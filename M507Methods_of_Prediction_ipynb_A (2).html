INTRODUCTION

n highly competitive subscription-based industries such as telecommunications, retaining customers is crucial for sustaining long-term profitability. Customer churn, which refers to customers discontinuing a service, results in revenue loss and increased operational costs due to marketing, onboarding, and acquisition of new customers. As a result, understanding and predicting churn has become a strategic priority for businesses.

The Telco Customer Churn dataset provides comprehensive customer-level information, including demographic characteristics, service usage patterns, contract types, and payment behaviour. Analysing these variables makes it possible to identify behavioural trends that differentiate loyal customers from those likely to leave.

This project presents an end-to-end machine learning approach for predicting customer churn using a deep learning model. The workflow includes data exploration, preprocessing, model development, experimentation with multiple configurations, and evaluation using standard classification metrics.

Business Problem

Telecommunication companies operate in a highly competitive environment where customer retention plays a critical role in maintaining stable revenue streams. When customers leave the service, the organisation not only loses recurring income but also incurs additional costs related to customer replacement and marketing efforts.

Currently, the absence of a predictive system means that churn is identified only after customers have already terminated their contracts. This reactive approach prevents the company from taking timely action. Without an effective prediction mechanism, the organisation is unable to:

Proactively identify customers with a high risk of churn

Understand the primary factors influencing customer decisions

Implement targeted retention strategies

Minimise avoidable revenue losses

from tensorflow.keras import layers, models, optimizers, callbacks

input_dim = X_train.shape[1]

def build_model(config, input_dim=input_dim):
    # config: dict with keys: hidden_layers (list), dropout, lr
    model = models.Sequential()
    model.add(layers.Input(shape=(input_dim,)))
    for units in config.get('hidden_layers', [64,32]):
        model.add(layers.Dense(units, activation='relu'))
        if config.get('batchnorm', False):
            model.add(layers.BatchNormalization())
        if config.get('dropout', 0) > 0:
            model.add(layers.Dropout(config['dropout']))
    model.add(layers.Dense(1, activation='sigmoid'))
    opt = optimizers.Adam(learning_rate=config.get('lr', 1e-3))
    model.compile(optimizer=opt, loss='binary_crossentropy', metrics=['accuracy'])
    return model

# Example model

import time
experiments = [
    {'name':'baseline','hidden_layers':[64,32],'dropout':0.2,'lr':1e-3,'batchnorm':True,'batch_size':64},
    {'name':'smaller','hidden_layers':[32,16],'dropout':0.1,'lr':1e-3,'batchnorm':False,'batch_size':64},
    {'name':'larger','hidden_layers':[128,64],'dropout':0.3,'lr':5e-4,'batchnorm':True,'batch_size':128},
    {'name':'no_dropout','hidden_layers':[64,32],'dropout':0.0,'lr':1e-3,'batchnorm':True,'batch_size':64},
    {'name':'higher_lr','hidden_layers':[64,32],'dropout':0.2,'lr':1e-2,'batchnorm':True,'batch_size':64},
    {'name':'batchnorm_only','hidden_layers':[64,32],'dropout':0.0,'lr':1e-3,'batchnorm':True,'batch_size':64},
    {'name':'deep','hidden_layers':[128,64,32],'dropout':0.25,'lr':5e-4,'batchnorm':True,'batch_size':64},
    {'name':'shallow','hidden_layers':[32],'dropout':0.2,'lr':1e-3,'batchnorm':False,'batch_size':64},
    {'name':'classweights_off','hidden_layers':[64,32],'dropout':0.2,'lr':1e-3,'batchnorm':True,'batch_size':64,'use_class_weight':False},
    {'name':'smote_oversample','hidden_layers':[64,32],'dropout':0.2,'lr':1e-3,'batchnorm':True,'batch_size':64,'use_smote':True},
]

results = []
for exp in experiments:
    print("\nRunning:", exp['name'])
    start = time.time()
    # Prepare train data variant
    Xtr, ytr = X_train.copy(), y_train.copy()
    if exp.get('use_smote', False):
        sm = SMOTE(random_state=SEED)
        Xtr, ytr = sm.fit_resample(Xtr, ytr)
        cw_use = None
    else:
        cw_use = class_weights if exp.get('use_class_weight', True) else None

    model = build_model(exp)
    hist = model.fit(
        Xtr, ytr,
        validation_split=0.15,
        epochs=30,
        batch_size=exp.get('batch_size',64),
        class_weight=cw_use,
        callbacks=[callbacks.EarlyStopping(monitor='val_loss', patience=5, restore_best_weights=True)],
        verbose=0
    )
    val_acc = hist.history['val_accuracy'][-1]
    val_loss = hist.history['val_loss'][-1]
    # Evaluate on test set with probabilities
    yprob = model.predict(X_test).ravel()
    ypred = (yprob >= 0.5).astype(int)
    test_auc = roc_auc_score(y_test, yprob)
    test_f1 = f1_score(y_test, ypred)
    results.append({
        'experiment': exp['name'],
        'val_acc': round(val_acc,4),
        'val_loss': round(val_loss,4),
        'test_auc': round(test_auc,4),
        'test_f1': round(test_f1,4),
        'time_s': int(time.time()-start)
    })
    print(f"Done {exp['name']}: val_acc={val_acc:.4f}, test_auc={test_auc:.4f}, test_f1={test_f1:.4f}")

baseline_auc = roc_auc_score(y_test, final_model.predict(X_test).ravel())
importances = []
cols = preprocessor.get_feature_names_out()

14.Final Discussion, Business problem & solution

Key findings (short):

tenure is among the strongest negative predictors of churn (short tenure → high churn).

Contract type (month-to-month) and InternetService (fiber) frequently show higher churn rates.

MonthlyCharges has a positive association with churn (higher charges → higher churn risk).

Business solution:¶

Targeted retention: Prioritise customers with short tenure and month-to-month contracts for onboarding calls and tailored offers.

Pricing & offers: Review expensive plans and present value-added promotions or payment plans for high monthly charges customers.

Value-based interventions: Use churn probability scores to direct discounts or premium support to customers where expected retention ROI is high.

Monitor model drift: Retrain the model regularly (monthly/quarterly) as customer behaviour and offers change.

Deployment notes:

Export model as SavedModel or HDF5 and serve via a lightweight API (Flask/FastAPI) or batch scoring pipeline.

Provide churn probability + top reasons (via SHAP/permutation results) to business users for explainable actions.

Monitor performance and business KPIs (reduction in churn, retention campaign ROI).
